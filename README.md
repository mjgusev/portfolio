Misha Gusev — Portfolio
=======================

Tech stack
- Next.js 15 (App Router), React 19, TypeScript
- Tailwind CSS v4

Local dev
- cd `site`
- `npm install`
- `npm run dev` → http://localhost:3000

Build
- `npm run build`
- `npm start`

Project structure
- `src/app` — routes and global styles
- `src/components` — UI components
- `src/data` — structured resume data
- `public` — static assets (SVGs, resume)

Accessibility
- Semantic HTML, sufficient color contrast, focusable links/buttons
- Command palette uses ARIA dialog semantics and Escape to close
